# Sudoku Bloom

A relaxing Sudoku puzzle game prototype with three always-available difficulties, multiple visual themes, pencil notes, number highlighting and progression milestones.

## Run locally

Open `index.html` in any modern browser once it is uploaded.

## Vercel

Import this GitHub repository at https://vercel.com/new. Choose **Other** framework, leave the build command blank, and use the repository root as the output directory. The app is a static website, with `index.html` as its homepage.

## Status

Prototype. A native iOS App Store build is a separate next stage.
